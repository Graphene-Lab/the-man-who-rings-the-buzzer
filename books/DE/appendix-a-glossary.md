# Anhang A — Vollständiges Glossar

Jeder Verkaufs-, Psychologie-, Verhandlungs-, Kultur- und Marketingbegriff aus diesem Buch, in einer A-Z-Tabelle. Jeder hat eine schlichte einzeilige Definition. Wenn Sie ein Wort hier nicht in einem Atemzug erklären können, benutzen Sie es nicht an einer Tür.

| Begriff | Schlichte Definition |
|---|---|
| A/B-Testing | Zwei Versionen (A und B) an ähnlichen Interessenten vergleichen und die behalten, die gewinnt. |
| Account-based Marketing (ABM) | Erst eine Kurzliste namentlich genannter Zielunternehmen wählen, dann alles darauf zuschneiden, sie zu gewinnen. |
| Anker | Die erste Zahl auf dem Tisch, die jede Zahl danach rahmt. |
| Autorität | Einfluss, der aus gezeigtem oder dokumentiertem Wissen kommt, nicht aus dem Behaupten davon. |
| BATNA | Ihre beste Option, wenn Sie aus dem Deal aussteigen (Best Alternative to a Negotiated Agreement). |
| Baseline | Ihr aktueller Wert, vor einer Änderung gemessen, damit Sie sehen können, ob die Änderung half. |
| Klingel | Der Tür-zu-Tür-Verkäufer, der die Sprechanlage persönlich betätigt; auch der Akt des Auftauchens selbst. |
| Käufer-Persona | Ein Profil Ihres idealen Käufers, gebaut aus echten Merkmalen wie Rolle, Größe und Problem. |
| Abschluss | Klar um die Zustimmung bitten; eine Bitte, kein Hinterhalt. |
| Kaltanruf / kalte Klingel | Kontakt mit jemandem, der keine vorherige Beziehung zu Ihnen hat und nicht kontaktiert werden wollte. |
| Commitment | Ein kleines Ja, das eine Person dann einhalten will, was ein größeres Ja wahrscheinlicher macht. |
| Zugeständnis | Etwas, das Sie in einer Verhandlung geben; es sollte getauscht werden, nie einfach geschenkt. |
| Konsistenz | Im Einklang mit dem handeln, was eine Person bereits über sich oder ihre Wünsche gesagt hat. |
| Konversionsrate | Der Anteil der Versuche, die den nächsten Schritt erreichen (zum Beispiel zwei Meetings aus zwanzig Türen sind 10 %). |
| CRM | Software, die jeden Kontakt und jeden Deal aufzeichnet (Customer Relationship Management). |
| Cross-Selling | Ein zusätzliches, verwandtes Produkt neben dem verkaufen, das sie wollen. |
| Entscheider | Die Person, die Ja sagen und unterschreiben kann. |
| Discovery | Die Fragephase, in der Sie die echten Bedürfnisse des Käufers finden, bevor Sie pitchen. |
| Aufzugspitch / 30-Sekunden-Pitch | Eine sehr kurze, fertige Zusammenfassung, wer Sie sind und welchen Wert Sie bringen. |
| Nachfassen | Der Kontakt, den Sie nach einem Meeting oder einem Angebot machen, um den Deal in Bewegung zu halten. |
| Funnel | Die Stufen, die ein Käufer durchläuft, oben breit und beim Abschluss schmal. |
| Gatekeeper | Die Person, die den Zugang zum Entscheider kontrolliert, oft an der Rezeption. |
| Guanxi | In China das Netz vertrauenswürdiger Beziehungen, das Geschäft möglich macht. |
| Growth Hacking | Schnelle, kostengünstige Experimente, um zu finden, was ein Geschäft wachsen lässt, dann das Skalieren des Funktionierenden. |
| Hochkontextkultur | Eine Kultur, in der viel Bedeutung unausgesprochen bleibt und aus der Situation gelesen wird. |
| ICP | Die Art Unternehmen, die am besten zu Ihnen passt (Ideal Customer Profile). |
| Inbound-Marketing | Käufer mit nützlichen Inhalten zu sich ziehen, statt ihnen hinterherzujagen. |
| Key-Account-Management (KAM) | Ihren wertvollsten Bestandskunden besondere, persönliche Aufmerksamkeit geben. |
| KPI | Eine Zahl, die Sie verfolgen, um Leistung zu messen (Key Performance Indicator). |
| Lead | Eine Person oder Firma, die vielleicht kauft, aber noch nicht geprüft oder qualifiziert ist. |
| Lead-Scoring | Leads nach ihrer Kaufwahrscheinlichkeit reihen, damit Sie die besten zuerst anrufen. |
| Hebel | Etwas, das Sie tauschen können und das die andere Seite schätzt, oft billiger als Preis. |
| Sympathie | Wärme und Einfluss durch Ähnlichkeit, ehrliches Lob und Zusammenarbeit. |
| Niedrigkontextkultur | Eine Kultur, in der Bedeutung klar und direkt ausgesprochen wird. |
| Manipulation | Ein Überzeugungshebel, der gegen das eigene Interesse des Kunden eingesetzt wird. |
| Nemawashi | In Japan der stille Konsensaufbau hinter den Kulissen vor einer Entscheidung. |
| Neuromarketing | Die Studie, wie das Gehirn auf Marketing und auf andere Menschen reagiert. |
| Nurturing | Steter, nützlicher Kontakt, der einen noch nicht bereiten Käufer über Zeit warm hält. |
| Einwand | Ein geäußertes Zweifel, Sorge oder Verweigerung, das Sie beantworten, bevor der Deal sich bewegen kann. |
| Outbound | Ihre Botschaft zu Menschen drücken, die sie nicht angefordert haben (Kaltanrufe, kalte Klingeln). |
| Schmerzpunkt | Das bestimmte Problem, das den Käufer Geld, Zeit oder Sorge kostet. |
| Überzeugung | Jemandem zu einer Entscheidung helfen, indem man an sein tatsächliches Denken appelliert. |
| Pipeline | Die volle Liste Ihrer offenen Deals, nach Stufe sortiert. |
| Machtdistanz | Wie sehr eine Kultur ungleichen Rang und Autorität akzeptiert. |
| Qualifizieren | Prüfen, ob ein Lead das Bedürfnis, das Budget und die Autorität zum Kauf hat. |
| Rapport | Ein Gefühl leichter Vertrauen und Verbindung zwischen zwei Menschen. |
| Reziprozität | Menschen fühlen sich verpflichtet, einen Gefallen zu erwidern, also kann erstes Geben eine Tür öffnen. |
| Empfehlung | Eine Weiterempfehlung eines bestehenden Kontakts, der Sie einem neuen Interessenten vorstellt. |
| ROI | Was Sie zurückbekommen im Vergleich zu dem, was Sie ausgeben (Return on Investment). |
| Verknappung | Wert, der aus einer echten, ehrlichen Grenze bei Angebot oder Zeit kommt. |
| Sensorisches Marketing | Wie sich ein Käufer fühlt, durch die fünf Sinne formen: Stimme, Berührung, Blick, Raum. |
| Social Proof | Der Beleg, dass Leute wie der Käufer es schon getan haben, was die Wahl sicher fühlen lässt. |
| Zielkonto | Ein bestimmtes Unternehmen, das Sie zu verfolgen gewählt haben. |
| TCO | Die vollen Kosten des Besitzes über Zeit, nicht nur der Preis (Total Cost of Ownership). |
| Bedrohungsreaktion | Die Abwehr des Gehirns, die den Kauf blockiert, wenn sich eine Person gehetzt oder bedrängt fühlt. |
| Testabschluss | Eine Testfrage vor der letzten Bitte, um früh ein Ja zu prüfen. |
| Unity | Geteilte Identität — „einer von uns" — ein stärkerer Hebel als einfache Sympathie. |
| Upselling | Eine höhere oder größere Version von dem verkaufen, was der Käufer schon will. |
| USP | Was Sie von jedem Rivalen unterscheidet (Unique Selling Proposition). |
| Wertversprechen | Das klare Versprechen des Nutzens, das Sie dem Käufer bieten. |
| Aufwärmen | Ein Ziel Ihnen vertraut machen, und Sie ihm, bevor Sie Kontakt aufnehmen. |
| Gewinn-/Verlust-Analyse | Auf einen abgeschlossenen Deal zurückblicken, um zu lernen, warum er gewonnen oder verloren wurde. |
| Ja-Leiter | Eine Folge kleiner, leichter Zustimmungen, die die echte Bitte natürlich wirken lässt. |
| ZOPA | Der Bereich, in dem ein Deal für beide Seiten möglich ist (Zone of Possible Agreement). |
