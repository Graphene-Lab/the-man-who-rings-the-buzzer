# CRM und Technologie für den Verkäufer

## Ziele

Nach diesem Kapitel können Sie:

- Ein CRM wählen, das zu Ihrem tatsächlichen Verkaufsstil passt, statt eine Broschüre zu kaufen.
- Stufen, Felder und Ergebnis-Codes so konfigurieren, dass Ihre Berichte sich selbst aufbauen.
- Das Nachfassen automatisieren, damit nichts von Ihrem Gedächtnis abhängt.
- Routing-Werkzeuge und Intent-Daten-Signale nutzen, um Tür-Zeit dort einzusetzen, wo sie sich lohnt.
- Ihren eigenen Tech-Stack auditieren und die manuellen Übergabestellen entfernen, wo Daten sterben.

## Kernkonzepte

### Das Werkzeug ist nicht die Strategie

Die Werkzeugkiste eines Verkäufers enthält heute ein CRM, einen Kalender, E-Mail, ein Telefon, Karten, LinkedIn, vielleicht einen Intent-Daten-Dienst und einen KI-Assistenten. Keines davon macht Sie zu einem besseren Abschlussspezialisten. Was sie tun — wenn gut miteinander verdrahtet — ist, Ihre Strategie **wiederholbar** zu machen: Die gute Woche wird die normale Woche, und die schlechte Woche zeigt sich in den Daten statt in Ihren Gefühlen. Die Regel für alles Folgende: Ein Werkzeug verdient seinen Platz nur, wenn es einen manuellen Schritt entfernt oder ein Stück Information schützt, das Sie sonst verlieren würden.

### Das CRM auswählen und konfigurieren

Das CRM haben Sie im letzten Kapitel kennengelernt: die Datenbank jeder Firma, jedes Gesprächs und jedes Abschlusses. Die Auswahl ist eine Kurzliste aus fünf Fragen:

| Kriterium | Worauf Sie achten sollten | Warum es für den Klingel-Verkäufer zählt |
|-----------|------------------|--------------------------------------|
| Mobil zuerst | Schnell auf dem Telefon, einhändig bedienbar | Sie erfassen am Tor, nicht am Schreibtisch |
| Schnelle Eingabe | Ein Kontakt in unter 60 Sekunden, Sprachdiktat von Vorteil | Langsame Eingabe bedeutet keine Eingabe |
| Eigene Stufen | Stufen, die Sie benennen, in Ihrer Reihenfolge | Die Pipeline muss echte Gespräche abbilden |
| Ergebnis-Codes | Pflicht-Auswahlliste bei jeder Aktivität | Das macht Berichte ehrlich |
| Integrationen | E-Mail, Kalender, Karten, Datentools | Jede fehlende Verbindung ist manuelles Kopieren |

Ein Einzelverkäufer oder ein kleines Team sollte die Schwere von Enterprise-CRMs meiden: zehn Pflichtfelder pro Kontakt ist ein System für eine Vertriebsabteilung mit Administrator. Es wird von einem Verkäufer, der Türen klingeln muss, aufgegeben werden.

Konfigurieren Sie das CRM **um die Klingel herum**. Die Stufen sollten wie Ihr echter Tag lesen:

> Versuch unternommen → Kontakt hergestellt → Termin gebucht → Angebot gesendet → Gewonnen / Verloren

Dann fügen Sie die Felder hinzu, die Ihre KPIs brauchen: Branche, Unternehmensgröße, Passung zu Ihrem idealen Kundenprofil, Empfehlungsquelle. Jedes Feld sollte eine Frage beantworten, die Sie im Wochenreview stellen; wenn Sie die Frage nicht benennen können, löschen Sie das Feld. Ein CRM ist kein Museum für alles, was Sie wissen — es ist ein Armaturenbrett.

### Das Nachfassen automatisieren

Beim Nachfassen wird der Kaltverkauf gewonnen und das Gedächtnis versagt. Automatisierung gibt es auf drei Stufen:

1. **Erinnerungen.** Das CRM pingt Sie: „Rückfällig: Rossi, Dienstag." Besser als nichts, hängt aber noch davon ab, dass Sie jedes Mal die Nachricht selbst schreiben.
2. **Sequenzen.** Eine vorbereitete Kette von Nachrichten nach Zeitplan — ein Dank nach dem Termin, ein Anstupser an Tag vier, eine Fallstudie an Tag zehn. Sie genehmigen, das System sendet.
3. **Geplante Agenten.** Ein Assistent, der das Nachfassen von Anfang bis Ende betreibt: Er weiß, wer still geworden ist, entwirft die Nachricht in Ihrem Ton, sendet sie pünktlich und erfasst die Antwort — während Sie irgendwo anders Klingeln betätigen.

Stufe drei erforderte früher eine Marketingabteilung. Ein selbst gehosteter KI-Assistent bringt sie zu einer Person: Sie vereinbaren den Zeitplan einmal („jeden Werktag um 8 Uhr…", „jeden Freitag um 17 Uhr…"), und er vergisst nie, schläft nie und hält jeden Datensatz auf Ihrem eigenen Rechner. Eine Warnung, die auf jeder Stufe gilt: Automatisierung sendet, was Sie ihr zu senden sagen. Eine Sequenz mit einer schlechten Nachricht ist eine Maschine, um einen schlechten Eindruck schneller zu machen. Schreiben Sie die Nachricht wie ein Mensch, dann überlassen Sie der Maschine die Pünktlichkeit.

### Gebiets-Routing und Planungs-Werkzeuge

Ein Tag Kaltbesuche hat einen stillen Killer: Fahren zwischen unverbundenen Adressen. Die Gebietsarbeit aus den früheren Kapiteln zahlt sich hier mit **Routenoptimierung** aus — Ihre Stopps so anordnen, dass der Tag nach Zonen gebündelt ist statt quer über die Karte. Das Muster:

- **Wöchentlich:** Wählen Sie die Zone für die Woche aus Ihrer Zielliste.
- **Täglich:** Ordnen Sie die Stopps so, dass Sie eine enge Schleife laufen; stellen Sie Besuche mit Zeitfenster zuerst.
- **Unterwegs:** Eine Karte, eine Liste, kein Improvisieren zwischen Adressen.

Das ist kein Luxus. Streichen Sie eine Stunde Fahrzeit pro Tag, und Sie haben fünf Klingeln pro Tag hinzugefügt, vierzig im Monat, ohne einen zusätzlichen Schweißtropfen. Karten-Werkzeuge, die für eine Adressliste eine effiziente Reihenfolge berechnen, machen aus diesem Rätsel einen Ein-Minuten-Schritt.

### Integration mit LinkedIn und Intent-Daten-Tools

Zwei Signalquellen machen die Klingel klüger, bevor Sie das Haus verlassen.

**LinkedIn** beantwortet: *Wer sitzt in diesem Gebäude, und was hat sich geändert?* Ein neuer Manager hat vor drei Wochen angefangen (neuer Entscheider, neues Budget). Eine Firma hat über Expansion gepostet (neue Bedürfnisse). Eine gemeinsame Verbindung könnte Sie vorstellen. Prüfen Sie die Zielfirma am Morgen des Besuchs; eine frische Tatsache macht aus einem kalten Einstieg einen warmen.

**Intent-Daten** sind Informationen darüber, welche Firmen aktiv genau die Art von Problem recherchieren, das Sie lösen — Suchen, Seitenbesuche auf Vergleichsseiten, Themen-Engagement, verkauft von Spezialdiensten. In einfachen Worten: Manche Firmen suchen bereits nach Ihnen; Intent-Daten sagen Ihnen, welche. Das Integrationsmuster:

> Intent-Signal → Aufgabe im CRM → kurze Recherche → gebündelt in eine Klingel-Route

Zwei ehrliche Warnungen. Erstens: Intent-Daten sind ein Hinweis, kein Versprechen — eine Firma, die ein Thema recherchiert, kann ein Student, ein Journalist oder ein Wettbewerber sein. Zweitens: Er ersetzt nie die Prospekt-Recherche, die Sie früher gelernt haben; er priorisiert sie. Der Verkäufer, der eine „Intent"-Firma ohne Vorbereitung anklingelt, wird immer noch rausgeklingelt.

### Der vernetzte Stack: eine einzige Wahrheit

Das ganze Kapitel reduziert sich auf ein Prinzip: **eine einzige Wahrheit, alles speist sie ein oder liest aus ihr.** Das CRM ist die Wahrheit. E-Mail, Kalender, LinkedIn, Karten und der KI-Assistent sollten entweder hineinschreiben oder daraus lesen. Jedes manuelle Copy-Paste zwischen Werkzeugen ist ein Ort, wo Daten sterben — und tote Daten bedeuten tote Prognosen. Zählen Sie Ihre Übergaben: Wenn Sie einen Termin per Hand aus der E-Mail ins CRM kopieren, ist das ein Leck. Schließen Sie es mit Integration oder Automatisierung.

## Terminologie in der Praxis

| Begriff | Schlichte Bedeutung | In einem Satz verwendet |
|------|---------------|--------------------|
| CRM | Die Datenbank jedes Kontakts, Gesprächs und Abschlusses | „Wenn es nicht im CRM steht, ist es nicht passiert." |
| Pipeline-Stufe | Ein benannter Schritt, den Ihre Abschlüsse durchlaufen | „Schieb Rossi auf ‚Angebot gesendet'." |
| Ergebnis-Code | Ein festes Label für das, was bei jedem Versuch passierte | „Erfasse es als ‚Gatekeeper blockiert', nicht als ‚nichts'." |
| Sequenz | Eine vorbereitete Kette von Nachfass-Nachrichten nach Zeitplan | „Er kam nach dem Termin in die Nachfass-Sequenz." |
| Routenoptimierung | Stopps so ordnen, dass Fahrzeit minimiert wird | „Der Routenplan machte aus fünf verstreuten Stopps eine Schleife." |
| Intent-Daten | Signale, dass eine Firma Ihr Problemergebiet recherchiert | „Die Intent-Liste gab mir zehn warme Türen diese Woche." |
| Integration | Zwei Werkzeuge tauschen automatisch Daten aus | „Die E-Mail-Integration killt den Copy-Paste-Schritt." |
| Single Source of Truth | Ein System, in dem die echten Datensätze liegen | „Das CRM ist die Wahrheit; alles andere ist ein Fenster." |

## AgentBridge in Aktion

Hier ist der vernetzte Stack in einem Assistenten. Am Morgen richten Sie ihn einmal ein:

> **Gib mir jeden Werktag um 8 Uhr eine Zusammenfassung der Verkäufe von gestern und aller dringenden E-Mails.**

Die geplante Aufgabe läuft von allein und hat die Zusammenfassung wartend — kein Gedächtnis nötig. Tagsüber liest derselbe Agent Ihr echtes Geschäftssystem: Tippen Sie *„Wie ist der Status von Auftrag 4821?"*, und er antwortet aus dem verbundenen ERP in klaren Worten, sodass Sie nie einen Kunden in Warteschleife hängen lassen, um sich durch Menüs zu suchen. Am Nachmittag sind Sie auf einem anderen Rechner: Öffnen Sie den Browser-Chat, und es ist derselbe Assistent — dieselben Dokumente, dieselbe Erinnerung. Und wenn ein Angebot still wird, entwirft das Nachfass-Werkzeug den Anstupser, und eine geplante Aufgabe sendet ihn, falls keine Antwort eingeht.

**Verkaufsaspekt:** Ihre Technologie arbeitet das Büro ab, während Sie die Türen abarbeiten. Der Engpass des Klingel-Verkäufers ist nie der Mut — es ist alles rund um das Gespräch. Ein selbst gehosteter Assistent, der plant, abruft und nachfasst, entfernt das „rundherum", und er tut es mit Daten, die Ihre eigene Maschine nie verlassen.

## Eine Notiz aus der Praxis

Die CRM-Branche selbst begann mit der Frustration eines Verkäufers. Thomas Siebel verließ Oracle und gründete 1993 zusammen mit Pat House, seinem Kollegen aus Oracles früherer Arbeit an Vertriebstechnologie, die Siebel Systems. Die Firma verkaufte Software, die eines tat: jede Kundeninteraktion in einem System halten, damit Vertriebsteams aufhörten, Abschlüsse in ihren eigenen Köpfen zu verlieren. Es funktionierte — Siebel wurde 1999 zu *Fortune*s am schnellsten wachsendem Unternehmen Amerikas genannt, überschritt im Jahr 2000 eine Milliarde Dollar Umsatz und hielt 2002 einen Spitzenanteil von 45 % am CRM-Markt, bevor Oracle es 2005 für 5,8 Milliarden Dollar kaufte. Die Lehre für einen Einzelverkäufer mit Telefon und Notizbuch: Die Firma, die Kundenwissen systematisiert, wird sehr wertvoll — und diese Lehre passt in ein Ein-Personen-Geschäft, bevor sie in einen Konzern passt. (Quelle: Wikipedia, „Siebel Systems".)

## Übungen

1. **Der 60-Sekunden-Test.** Stoppen Sie sich, wie lange Sie brauchen, um einen echten Kontakt in Ihrem CRM zu erfassen, vom Zuschlagen der Tür bis zum gespeicherten Datensatz. Wenn es länger als 60 Sekunden dauert, finden Sie den Schritt, den Sie streichen können — ein Pflichtfeld, eine umständliche Maske, kein Diktat. Beheben Sie es diese Woche.
2. **Kartieren Sie Ihren Stack.** Listen Sie jedes Werkzeug auf, das Sie an einem Verkaufstag nutzen. Zeichnen Sie Pfeile, wo Daten zwischen ihnen fließen, und markieren Sie jeden Pfeil „automatisch" oder „per Hand". Jedes „per Hand" ist ein Leck. Schließen Sie das schlimmste mit einer Integration oder einer Automatisierung.
3. **Automatisieren Sie ein Nachfassen.** Richten Sie ein echtes Nachfassen ein, das ohne Sie läuft: mindestens eine Erinnerung, wenn möglich eine geplante Nachricht. Prüfen Sie beim ersten Lauf, ob es funktionierte.
4. **Bündeln Sie einen Tag.** Nehmen Sie zehn Zieladressen. Gruppieren Sie sie in Zonen und planen Sie einen Tag als enge Schleife mit einem Karten-Werkzeug. Vergleichen Sie die geplante Fahrzeit mit dem, wie Sie es letzten Monat gemacht hätten.

## Zusammenfassung

- Werkzeuge machen Sie nicht zu einem besseren Abschlussspezialisten; sie machen Ihre Strategie wiederholbar und Ihre Daten ehrlich.
- Konfigurieren Sie das CRM um die Klingel herum: mobil zuerst, 60-Sekunden-Erfassung, Stufen, die echte Gespräche abbilden, Pflicht-Ergebnis-Codes.
- Automatisieren Sie das Nachfassen in Stufen — Erinnerungen, Sequenzen, geplante Agenten —, aber schreiben Sie jede Nachricht zuerst wie ein Mensch.
- Bündeln Sie Besuche nach Zone und optimieren Sie die Route: eine gesparte Fahrstunde sind fünf Klingeln pro Tag.
- Halten Sie eine einzige Wahrheit. Jedes manuelle Copy-Paste zwischen Werkzeugen ist der Ort, wo Ihre Daten sterben.
