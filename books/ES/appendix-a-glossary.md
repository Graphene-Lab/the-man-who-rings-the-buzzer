# Apéndice A — Glosario completo

Todos los términos de ventas, psicología, negociación, cultura y marketing usados en este libro, en una sola tabla A-Z. Cada uno tiene una definición llana de una línea. Si no puede explicar una palabra de aquí de un solo aliento, no la use en una puerta.

| Término | Definición llana |
|---|---|
| Prueba A/B | Comparar dos versiones (A y B) en prospectos similares y quedarse con la que gana. |
| Marketing basado en cuentas (ABM) | Elegir primero una lista corta de empresas objetivo con nombre, y luego adaptar todo para ganarlas. |
| Anclaje | El primer número puesto sobre la mesa, que enmarca todos los números que vienen después. |
| Autoridad | Influencia que viene de un conocimiento mostrado o documentado, no de afirmarlo. |
| BATNA | Su mejor opción si se aparta del trato (Best Alternative to a Negotiated Agreement). |
| Línea base | Su resultado actual, medido antes de un cambio, para poder decir si el cambio ayudó. |
| Portero automático | El comercial que va de puerta en puerta y llama al interfono en persona; también el acto de presentarse en sí. |
| Buyer persona | Un perfil de su comprador ideal, construido a partir de rasgos reales como rol, tamaño y problema. |
| Cierre | Pedir con claridad el acuerdo; una petición, no una trampa. |
| Llamada en frío / portero automático en frío | Contacto con alguien que no tiene relación previa con usted y no pidió que le contactaran. |
| Compromiso | Un sí pequeño que la persona luego quiere honrar, lo que hace más probable un sí mayor. |
| Concesión | Algo que usted cede en una negociación; debe ser intercambiado, nunca regalado a secas. |
| Coherencia | Actuar en línea con lo que una persona ya ha dicho que es o que quiere. |
| Tasa de conversión | La proporción de intentos que alcanzan el siguiente paso (por ejemplo, dos reuniones de veinte puertas es el 10 %). |
| CRM | Software que registra cada contacto y trato (Customer Relationship Management). |
| Venta cruzada | Vender un producto extra y relacionado junto al que ellos quieren. |
| Tomador de decisiones | La persona que puede decir que sí y firmar. |
| Descubrimiento | La etapa de preguntas donde usted halla las necesidades reales del comprador antes de vender. |
| Discurso de ascensor / discurso de 30 segundos | Un resumen muy corto y listo de quién es usted y el valor que aporta. |
| Seguimiento | El contacto que hace tras una reunión o un presupuesto para mantener el trato en marcha. |
| Embudo | Las etapas por las que pasa un comprador, ancho arriba y estrecho en el cierre. |
| Portero | La persona que controla el acceso al tomador de decisiones, a menudo en recepción. |
| Guanxi | En China, la red de relaciones de confianza que hace posible el negocio. |
| Growth hacking | Experimentos rápidos y de bajo coste para hallar qué hace crecer un negocio, y luego escalar lo que funciona. |
| Cultura de alto contexto | Una cultura donde gran parte del significado se deja sin decir y se lee de la situación. |
| ICP | El tipo de empresa que mejor encaja con usted (Ideal Customer Profile). |
| Marketing de atracción (inbound) | Atraer compradores hacia usted con contenido útil en vez de perseguirlos. |
| Gestión de cuentas clave (KAM) | Dar a sus clientes actuales más valiosos una atención especial y personal. |
| KPI | Un número que usted rastrea para medir el desempeño (Key Performance Indicator). |
| Lead | Una persona o empresa que podría comprar, pero que aún no está comprobada ni cualificada. |
| Puntuación de leads | Clasificar los leads por su probabilidad de comprar, para llamar primero a los mejores. |
| Palanca | Algo que puede intercambiar y que la otra parte valora, a menudo más barato que el precio. |
| Simpatía | Calidez e influencia de la semejanza, el elogio honesto y la cooperación. |
| Cultura de bajo contexto | Una cultura donde el significado se expresa de forma llana y directa. |
| Manipulación | Una palanca de persuasión usada contra el interés del propio cliente. |
| Nemawashi | En Japón, la construcción silenciosa de consenso entre bambalinas antes de una decisión. |
| Neuromarketing | El estudio de cómo responde el cerebro al marketing y a las demás personas. |
| Nutrición (nurturing) | Contacto constante y útil que mantiene templado a un comprador aún no listo, con el tiempo. |
| Objeción | Una duda, preocupación o negativa expresada que usted responde antes de que el trato pueda avanzar. |
| Outbound | Empujar su mensaje a gente que no lo pidió (llamadas en frío, porteros automáticos en frío). |
| Punto de dolor | El problema concreto que le cuesta dinero, tiempo o preocupación al comprador. |
| Persuasión | Ayudar a alguien a llegar a una decisión apelando a cómo piensa de verdad. |
| Pipeline | La lista completa de sus tratos abiertos, ordenada por etapa. |
| Distancia al poder | Cuánto acepta una cultura el rango y la autoridad desiguales. |
| Calificación | Comprobar si un lead tiene la necesidad, el presupuesto y la autoridad para comprar. |
| Rapport | Una sensación de confianza y conexión fáciles entre dos personas. |
| Reciprocidad | La gente se siente obligada a devolver un favor, así que dar primero puede abrir una puerta. |
| Referido | Una recomendación de un contacto existente que le presenta a un nuevo prospecto. |
| ROI | Lo que obtiene de vuelta comparado con lo que gasta (Return on Investment). |
| Escasez | Valor que viene de un límite real y honesto en la oferta o el tiempo. |
| Marketing sensorial | Dar forma a cómo se siente un comprador a través de los cinco sentidos: voz, tacto, vista, espacio. |
| Prueba social | Evidencia de que gente como el comprador ya lo ha hecho, lo que hace la elección sentirse segura. |
| Cuenta objetivo | Una empresa concreta que usted ha elegido perseguir. |
| TCO | El coste total de poseer algo con el tiempo, no solo el precio (Total Cost of Ownership). |
| Respuesta de amenaza | La defensa del cerebro que bloquea la compra cuando una persona se siente apremiada o acorralada. |
| Cierre de prueba | Una pregunta de tanteo antes de la petición final, para comprobar un sí pronto. |
| Unidad | Identidad compartida: «de los nuestros»—, una palanca más fuerte que la simple simpatía. |
| Venta adicional (upselling) | Vender una versión superior o mayor de lo que el comprador ya quiere. |
| USP | Lo que le hace diferente de cada rival (Unique Selling Proposition). |
| Propuesta de valor | La promesa clara de beneficio que usted ofrece al comprador. |
| Calentamiento | Hacer que un objetivo le resulte familiar a usted, y usted a él, antes de hacer contacto. |
| Revisión de victorias y derrotas | Mirar hacia atrás un trato cerrado para aprender por qué se ganó o se perdió. |
| Escalera del sí | Una sucesión de acuerdos pequeños y fáciles que hace que la petición real parezca natural. |
| ZOPA | El rango donde un trato es posible para ambas partes (Zone of Possible Agreement). |
