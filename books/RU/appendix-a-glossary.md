# Приложение A — Полный глоссарий

Все термины этой книги — о продажах, психологии, переговорах, культуре и маркетинге — собраны в одну таблицу от А до Я. У каждого — простое определение в одну строку. Если слово не удаётся объяснить на одном дыхании, не употребляйте его у двери.

| Термин | Простое определение |
|---|---|
| A/B testing | Сравнение двух версий (A и B) на похожих перспективных клиентах и выбор той, что побеждает. |
| Account-based marketing (ABM) | Сначала выбрать короткий список конкретных целевых компаний, а затем подстроить всё под то, чтобы их выиграть. |
| Anchor (якорь) | Первая цифра, положенная на стол; она задаёт рамку для всех последующих цифр. |
| Authority (авторитет) | Влияние, которое приходит от показанных или задокументированных знаний, а не от заявлений о них. |
| BATNA | Ваш лучший вариант, если вы уйдёте от сделки (Best Alternative to a Negotiated Agreement). |
| Baseline (базовая линия) | Ваш текущий результат, измеренный до изменения, чтобы понять, помогло ли изменение. |
| Buzzer (домофон) | Продавец, который лично обходит двери и звонит в домофон; а также сам приход, само появление. |
| Buyer persona (портрет покупателя) | Профиль вашего идеального покупателя, построенный на реальных чертах: роль, размер, проблема. |
| Closing (закрытие) | Ясная просьба о согласии; это просьба, а не ловушка. |
| Cold call / cold buzzer (холодный звонок / холодный звонок в домофон) | Контакт с человеком, у которого нет с вами прежних отношений и который не просил, чтобы ему позвонили. |
| Commitment (обязательство) | Маленькое «да», которое человек затем хочет сдержать, делая большее «да» более вероятным. |
| Concession (уступка) | То, что вы даёте на переговорах; этим следует торговаться, а не просто дарить. |
| Consistency (последовательность) | Поступать в согласии с тем, о чём человек уже сказал, что он есть или чего хочет. |
| Conversion rate (коэффициент конверсии) | Доля попыток, достигающих следующего шага (например, две встречи с двадцати дверей — это 10%). |
| CRM (CRM) | Программа, записывающая каждый контакт и сделку (Customer Relationship Management). |
| Cross-selling (кросс-сейл) | Продажа дополнительного, связанного продукта вместе с тем, который они хотят. |
| Decision maker (ЛПР) | Человек, который может сказать «да» и подписать. |
| Discovery (выявление потребностей) | Этап вопросов, на котором вы узнаёте настоящие потребности покупателя до подачи предложения. |
| Elevator pitch / 30-second pitch (питч в лифте / питч за 30 секунд) | Очень короткая, готовая сводка о том, кто вы и какую ценность приносите. |
| Follow-up (фоллоу-ап) | Контакт, который вы делаете после встречи или коммерческого предложения, чтобы сделка двигалась. |
| Funnel (воронка) | Этапы, которые проходит покупатель: широкие вверху и узкие к закрытию. |
| Gatekeeper (привратник) | Человек, контролирующий доступ к лицу, принимающему решение, часто на ресепшене. |
| Guanxi (гуаньси) | В Китае — сеть доверительных отношений, делающая бизнес возможным. |
| Growth hacking | Быстрые недорогие эксперименты, чтобы найти то, что заставляет бизнес расти, а затем масштабировать то, что работает. |
| High-context culture (высококонтекстная культура) | Культура, где большая часть смысла остаётся несказанной и считывается из ситуации. |
| ICP | Тип компании, которая подходит вам лучше всего (Ideal Customer Profile). |
| Inbound marketing (инбаунд-маркетинг) | Привлечение покупателей к себе полезным контентом вместо того, чтобы бегать за ними. |
| Key account management (KAM) | Особое, персональное внимание к самым ценным существующим клиентам. |
| KPI | Число, которое вы отслеживаете для измерения эффективности (Key Performance Indicator). |
| Lead (лид) | Человек или компания, которые могут купить, но ещё не проверены и не квалифицированы. |
| Lead scoring (скоринг лидов) | Ранжирование лидов по вероятности покупки, чтобы сначала звонить лучшим. |
| Lever (рычаг) | То, чем вы можете торговать и что ценит другая сторона, часто дешевле, чем цена. |
| Liking (симпатия) | Тепло и влияние, рождённые сходством, искренней похвалой и сотрудничеством. |
| Low-context culture (низкоконтекстная культура) | Культура, где смысл высказывается прямо и недвусмысленно. |
| Manipulation (манипуляция) | Рычаг убеждения, направленный против собственных интересов клиента. |
| Nemawashi (нэмаваси) | В Японии — тихое закулисное согласование перед решением. |
| Neuromarketing (нейромаркетинг) | Изучение того, как мозг реагирует на маркетинг и на других людей. |
| Nurturing (прогрев) | Ровный, полезный контакт, который держит ещё не готового покупателя тёплым со временем. |
| Objection (возражение) | Высказанные сомнение, опасение или отказ, на которые нужно ответить, прежде чем сделка сдвинется. |
| Outbound (аутбаунд) | Проталкивание своего сообщения людям, которые о нём не просили (холодные звонки, холодные звонки в домофон). |
| Pain point (боль) | Конкретная проблема, которая стоит покупателю денег, времени или беспокойства. |
| Persuasion (убеждение) | Помочь человеку принять решение, обращаясь к тому, как он на самом деле мыслит. |
| Pipeline (воронка сделок) | Полный список ваших открытых сделок, разложенный по этапам. |
| Power distance (дистанция власти) | Насколько культура принимает неравенство ранга и авторитета. |
| Qualifying (квалификация) | Проверка, есть ли у лида потребность, бюджет и полномочия, чтобы купить. |
| Rapport (раппорт) | Ощущение лёгкого доверия и связи между двумя людьми. |
| Reciprocity (взаимность) | Люди чувствуют себя обязанными ответить на услугу, поэтому первый дар может открыть дверь. |
| Referral (рекомендация) | Рекомендация от уже знакомого контакта, которая представляет вас новому перспективному клиенту. |
| ROI | Что вы получаете обратно по сравнению с тем, что тратите (Return on Investment). |
| Scarcity (дефицит) | Ценность, рождённая реальным, честным ограничением предложения или времени. |
| Sensory marketing (сенсорный маркетинг) | Формирование того, что чувствует покупатель, через пять чувств: голос, осязание, зрение, пространство. |
| Social proof (социальное доказательство) | Доказательство того, что подобные покупателю люди уже это сделали, от чего выбор кажется безопасным. |
| Target account (целевая компания) | Одна конкретная компания, которую вы выбрали для преследования. |
| TCO | Полная стоимость владения чем-либо со временем, а не только цена (Total Cost of Ownership). |
| Threat response (реакция на угрозу) | Защита мозга, блокирующая покупку, когда человека торопят или припирают. |
| Trial close (пробное закрытие) | Пробный вопрос перед финальной просьбой, чтобы рано проверить «да». |
| Unity (единство) | Общая идентичность — «свой» — более сильный рычаг, чем простая симпатия. |
| Upselling (апсейл) | Продажа более высокой или большей версии того, что покупатель уже хочет. |
| USP | То, что отличает вас от каждого соперника (Unique Selling Proposition). |
| Value proposition (ценностное предложение) | Ясное обещание выгоды, которое вы предлагаете покупателю. |
| Warm-up (разогрев) | Сделать цель знакомой вам, а вас — ей, ещё до контакта. |
| Win/loss review (разбор побед и поражений) | Взгляд назад на закрытую сделку, чтобы понять, почему она выиграна или проиграна. |
| Yes ladder (лестница «да») | Череда маленьких лёгких согласий, от которой настоящая просьба кажется естественной. |
| ZOPA | Диапазон, где сделка возможна для обеих сторон (Zone of Possible Agreement). |
