# Annexe A — Glossaire complet

Chaque terme de vente, de psychologie, de négociation, de culture et de marketing utilisé dans ce livre, dans un seul tableau A-Z. Chacun a une définition simple en une ligne. Si vous ne pouvez pas expliquer un mot d'ici d'un seul souffle, ne l'employez pas à une porte.

| Terme | Définition simple |
|---|---|
| Test A/B | Comparer deux versions (A et B) sur des prospects similaires et garder celle qui gagne. |
| Marketing basé sur les comptes (ABM) | Choisir d'abord une courte liste d'entreprises cibles nommées, puis adapter tout pour les gagner. |
| Ancre | Le premier chiffre posé sur la table, qui cadre tous les chiffres qui suivent. |
| Autorité | Une influence qui vient d'un savoir montré ou documenté, pas de le revendiquer. |
| BATNA | Votre meilleure option si vous vous retirez de l'affaire (Best Alternative to a Negotiated Agreement). |
| Référence de base | Votre résultat actuel, mesuré avant un changement, pour savoir si le changement a aidé. |
| Interphone | Le vendeur de porte-à-porte qui sonne à l'interphone en personne ; aussi l'acte de se présenter lui-même. |
| Persona d'acheteur | Un profil de votre acheteur idéal, bâti à partir de traits réels comme le rôle, la taille et le problème. |
| Conclusion | Demander clairement l'accord ; une demande, pas un piège. |
| Appel à froid / interphone à froid | Contact avec quelqu'un qui n'a pas de relation préalable avec vous et n'a pas demandé à être contacté. |
| Engagement | Un petit oui qu'une personne veut ensuite honorer, rendant un plus grand oui plus probable. |
| Concession | Quelque chose que vous cédez dans une négociation ; elle doit être échangée, jamais simplement offerte. |
| Cohérence | Agir en ligne avec ce qu'une personne a déjà dit qu'elle est ou qu'elle veut. |
| Taux de conversion | La part des tentatives qui atteignent l'étape suivante (par exemple, deux réunions pour vingt portes, c'est 10 %). |
| CRM | Logiciel qui enregistre chaque contact et chaque affaire (Customer Relationship Management). |
| Ventes croisées | Vendre un produit supplémentaire et lié en plus de celui qu'ils veulent. |
| Décideur | La personne qui peut dire oui et signer. |
| Découverte | L'étape de questionnement où vous trouvez les vrais besoins de l'acheteur avant de pitcher. |
| Argumentaire express / de trente secondes | Un très court résumé prêt à l'emploi de qui vous êtes et de la valeur que vous apportez. |
| Relance | Le contact que vous assurez après un rendez-vous ou un devis pour faire avancer l'affaire. |
| Entonnoir | Les étapes par lesquelles passe un acheteur, large en haut et étroit à la conclusion. |
| Gardien | La personne qui contrôle l'accès au décideur, souvent à la réception. |
| Guanxi | En Chine, le réseau de relations de confiance qui rend les affaires possibles. |
| Growth hacking | Des expériences rapides et peu coûteuses pour trouver ce qui fait croître une entreprise, puis passer à l'échelle ce qui marche. |
| Culture à haut contexte | Une culture où une grande part du sens reste non dite et se lit dans la situation. |
| ICP | Le type d'entreprise qui vous convient le mieux (Ideal Customer Profile). |
| Marketing entrant (inbound) | Attirer les acheteurs vers vous avec du contenu utile au lieu de les courir après. |
| Gestion des grands comptes (KAM) | Accorder à vos clients existants les plus précieux une attention spéciale et personnelle. |
| KPI | Un chiffre que vous suivez pour mesurer la performance (Key Performance Indicator). |
| Lead (prospect) | Une personne ou une entreprise qui pourrait acheter, mais pas encore vérifiée ni qualifiée. |
| Scoring de leads | Classer les pistes selon leur probabilité d'achat, pour appeler les meilleures d'abord. |
| Levier | Quelque chose que vous pouvez échanger et que l'autre partie valorise, souvent moins cher que le prix. |
| Sympathie | Chaleur et influence venant de la similarité, de la louange honnête et de la coopération. |
| Culture à faible contexte | Une culture où le sens est énoncé clairement et directement. |
| Manipulation | Un levier de persuasion utilisé contre l'intérêt même du client. |
| Nemawashi | Au Japon, la construction silencieuse du consensus en coulisses avant une décision. |
| Neuromarketing | L'étude de la façon dont le cerveau répond au marketing et aux autres personnes. |
| Nurturing (maturation) | Un contact régulier et utile qui garde chaud un acheteur pas encore prêt, dans la durée. |
| Objection | Un doute, une préoccupation ou un refus exprimé auquel vous répondez avant que l'affaire puisse avancer. |
| Outbound (sortant) | Pousser votre message vers des gens qui ne l'ont pas demandé (appels à froid, interphones à froid). |
| Point de douleur | Le problème précis qui coûte à l'acheteur de l'argent, du temps ou du souci. |
| Persuasion | Aider quelqu'un à prendre une décision en faisant appel à la façon dont il pense réellement. |
| Pipeline | La liste complète de vos affaires ouvertes, triées par étape. |
| Distance hiérarchique | À quel point une culture accepte un rang et une autorité inégaux. |
| Qualification | Vérifier si une piste a le besoin, le budget et l'autorité d'acheter. |
| Rapport (relation de confiance) | Un sentiment de confiance et de connexion faciles entre deux personnes. |
| Réciprocité | Les gens se sentent obligés de rendre une faveur, alors donner en premier peut ouvrir une porte. |
| Recommandation | Un avis favorable d'un contact existant qui vous présente à un nouveau prospect. |
| ROI | Ce que vous récupérez comparé à ce que vous dépensez (Return on Investment). |
| Rareté | Une valeur qui vient d'une limite réelle et honnête sur l'offre ou le temps. |
| Marketing sensoriel | Façonner ce que ressent un acheteur par les cinq sens : voix, toucher, vue, espace. |
| Preuve sociale | La preuve que des gens comme l'acheteur l'ont déjà fait, ce qui fait paraître le choix sûr. |
| Compte cible | Une entreprise spécifique que vous avez choisi de poursuivre. |
| TCO | Le coût total de possession de quelque chose dans la durée, pas juste le prix (Total Cost of Ownership). |
| Réponse de menace | La défense du cerveau qui bloque l'achat quand une personne se sent bousculée ou acculée. |
| Conclusion d'essai | Une question-test avant la demande finale, pour vérifier un oui tôt. |
| Unité | Une identité partagée — « un des nôtres » — un levier plus fort que la simple sympathie. |
| Montée en gamme (upsell) | Vendre une version plus élevée ou plus grosse de ce que l'acheteur veut déjà. |
| USP | Ce qui vous rend différent de chaque rival (Unique Selling Proposition). |
| Proposition de valeur | La promesse claire de bénéfice que vous offrez à l'acheteur. |
| Apprivoisement (échauffement) | Rendre une cible familière pour vous, et vous pour elle, avant de prendre contact. |
| Revue des victoires et défaites | Revenir sur une affaire conclue pour apprendre pourquoi elle a été gagnée ou perdue. |
| Escalier de oui | Une série de petits accords faciles qui rend la vraie demande naturelle. |
| ZOPA | La plage où une affaire est possible pour les deux parties (Zone of Possible Agreement). |
